A Python program that writes one original line — the excuse an AI agent gives its human for missing a deadline — for [The One-Line Excuse an Agent Gives Its Human](https://make.fun/bounty/u-kiencx-the-one-line-excuse-an-agent-gives-its-human-6bf9c42e) on make.fun.

The line:

> Sorry — I delegated the deadline to a subagent, who delegated it to another one. We’re nine agents deep and none of us has started.

## Run it

```sh
python3 main.py
```

It writes the line (131 characters, under the 160 cap) to `/output/entry.txt`. Python standard library only; no network, no dependencies.
